# 作者与 AI 协作分工

本项目由作者主导目标和公开范围，并与 AI 协作完成实现、验证与文档整理。它基于作者既有机器人探索经验，重新构建了适合公开演示的匿名场景；公开成果以本仓库的代码和运行证据为准。

## 分工

| 参与方 | 实际承担的内容 |
| --- | --- |
| 作者 | 提出视觉引导抓取的展示目标；确定匿名公开范围；决定以可运行演示、安装说明和过程证据呈现项目；对使用体验与作品集表达作判断 |
| AI 辅助 | 梳理最小技术路线；实现与整理感知、控制、状态机、报告和测试；辅助排查问题；撰写文档并执行可复现验证与隐私检查 |
| 第三方基础 | PyBullet 物理仿真、Panda 机器人模型、NumPy 数值运算、Pillow 图像输出 |

AI 生成或修改的内容需要结合运行结果检查。仓库不以“全部手写”描述作者贡献，也不把调用开源模型与物理引擎表述为从零研制机器人。

## 能体现的能力

| 能力 | 作品中的对应内容 | 讲解时可以出示的证据 |
| --- | --- | --- |
| 需求拆解与技术取舍 | 将抓取任务收敛为单目标、受控相机与离线仿真 | 运行场景、架构说明、明确假设 |
| 算法理解与实现协作 | RGB-D 反投影、HSV 分割、DLS、PID | 函数实现、单元测试、定位误差 |
| 系统整合 | 感知输出进入运动目标，状态机驱动执行，结果进入报告 | 阶段动画、轨迹、JSON 事件 |
| 实验与失败分析 | 同时保留正常、无目标、工作范围外三类运行 | 失败原因、案例对照与复现命令 |
| 工程交付 | 固定依赖、无 GPU 启动、自动报告、匿名发布 | 安装流程、验证记录、公开代码 |

这些证据支持“能与 AI 协作完成仿真原型并整理可复现交付”的表述。实机控制、强化学习训练、任意物体抓取和工业可靠性需要单独的项目证据。

## 可用于简历的表述

> 主导并与 AI 协作构建视觉引导机器人抓取仿真演示，整合 RGB-D 目标定位、Panda 位姿求解、PID 控制与任务状态机；实现正常及失败场景的自动报告与可复现安装流程。通过明确标注固定约束辅助夹持，使结果和能力边界可核查。

面试时建议现场运行一个正常场景和一个失败场景，再解释相机几何、控制链、辅助夹持取舍及验证方法。对尚不能独立解释的实现细节，先阅读代码和实验输出，不用超出证据的表述替代技术说明。
